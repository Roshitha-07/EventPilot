
# ✨ EventPilot

### AI-Powered Event Management Platform

EventPilot is a smart event management platform that simplifies event planning, participant management, venue & speaker coordination, sponsorships, and incident handling — all in one place.

## 🚀 Features

- 🎟️ Participant Registration & Login
- 📊 Executive Dashboards & Analytics
- 🏢 Venue & Speaker Management
- 🤖 AI Event Intelligence & Agent Orchestration
- 🤝 Sponsorship Management
- 🚨 Incident Management & Alerts
- 📅 Event Scheduling & Check-in
- 🔍 End-to-End Testing & Deployment

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript

**Backend:** Python, Flask

**Database:** MySQL

**AI & Analytics:** Intelligent Agents, Chart.js

## ⚡ Getting Started

```bash
git clone https://github.com/Roshitha-07/EventPilot.git
cd EventPilot
pip install -r requirements.txt
python app.py
```

Open your browser and visit:

`http://127.0.0.1:5000`
